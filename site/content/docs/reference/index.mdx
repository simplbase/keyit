Everything before this page is task-oriented. This is the flat map: commands, files, relay operation, and source documents. Use it when you already know what you are looking for.

## Commands

```text
keyit init
keyit env add / list
keyit push / pull
keyit status / diff
keyit whoami
keyit revision list
keyit invite create
keyit join
keyit approve
keyit revoke
keyit relay check
keyit completions / version

keyit-relay serve
keyit-relay maintenance inspect / cleanup
keyit-relay completions / version
```

Every command supports `--help` for its full flag list. Day-to-day use lives under [Environments](/docs/environments) and Daily Use. Device lifecycle lives under [Team Access](/docs/access). Relay operation lives under [Relay](/docs/relay).
